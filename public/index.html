    How ARPGuard works

    Verdict fusion

    Rule alertKitsuneVerdict
    Gateway conflict / flip-flopHighConfirmed spoofing
    Other IP conflictHighProbable spoofing
    Flip-flopping, anyLowSuspicious, review
    Any one-off conflictLowLikely legitimate (log only)
    NoneHighAnomaly, not ARP
    NoneLowNormal

    "High" means at least 3 packets in the incident's window score above the threshold and they're at least 20% of that window. The AI never decides a verdict: it only explains the evidence the code produced, and its output is checked against that evidence.

    Rules on the binding table

    • Gateway MAC change: the gateway's IP claimed by an untrusted MAC (critical)
    • IP→MAC conflict: any IP claimed by a MAC that isn't its owner
    • Flip-flop: a binding bouncing between two MACs (re-poisoning)
    • One MAC, many IPs: one card answering for other hosts' addresses
    • Unsolicited reply: an "is-at" nobody asked for
    • ARP scan / flood: host discovery sweeps and broadcast overhead
    • DHCP-backed change: a move right after a DHCP ACK is logged as legitimate (DHCP snooping, in software)

    Parry and riposte fixing ARP spoofing on a switched LAN

    Dynamic ARP Inspection

    The switch checks every ARP packet on untrusted ports against the DHCP snooping table and drops forged ones.

    ip arp inspection vlan 10
interface Gi0/1
 ip arp inspection trust

    DHCP snooping

    Builds the trusted IP↔MAC↔port table that DAI uses, and blocks rogue DHCP servers.

    ip dhcp snooping
ip dhcp snooping vlan 10
interface Gi0/1
 ip dhcp snooping trust

    Port security

    Limit how many MACs a port may learn, so one cable can't impersonate a crowd.

    interface Gi0/5
 switchport port-security
 switchport port-security maximum 2
 switchport port-security violation restrict

    Static ARP for the gateway

    On critical hosts, pin the router's MAC so forged replies can't overwrite it.

    arp -s 192.168.1.1 50:c7:bf:3a:1c:01
netsh interface ipv4 add neighbors "Ethernet" 192.168.1.1 50-c7-bf-3a-1c-01

    Encrypt anyway

    HTTPS, SSH and VPNs keep intercepted traffic unreadable. Treat certificate warnings as an alarm.
