# Data

| File | What |
|---|---|
| `arp_mitm_synthetic.pcap` | 41k-packet labelled LAN capture: DHCP device change, printer NIC swap, a port scan, then an Ettercap-style ARP MitM (t = 450-693 s) |
| `arp_mitm_synthetic_labels.csv` | `index,label` per packet (1 = sent to or from the attacker during the attack) |
| `home_benign_synthetic.pcap` | 23k packets, no attack: a DHCP device change and a router replaced by a backup router (new gateway MAC) |
| `home_benign_synthetic_labels.csv` | all zeros |

All synthetic, generated by `scripts/make_synthetic_capture.py` (deterministic seed). Frames are
truncated to 96 bytes like the Kitsune captures, except DHCP, which is kept whole because the rule
engine reads DHCP options the way DHCP snooping does. Open them in Wireshark to take screenshots.

Not committed (see `.gitignore`):

* `kitsune/`: the real Kitsune ARP MitM capture and labels, via `python scripts/fetch_kitsune.py`
* `home_benign.pcap`: your own LAN, via `sudo python -m arpguard live --record data/home_benign.pcap`
* `oui.csv`: the full IEEE OUI registry (https://standards-oui.ieee.org/oui/oui.csv) for vendor lookup
